# Security Policy

## Supported versions

| Version | Status |
| --- | --- |
| 0.12.x Beta | Supported for security fixes |
| 0.11.x RC | Legacy comparison only |

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/mochiya-tako/InnerCorners/security/advisories/new) for vulnerabilities, unsafe cursor-control behavior, permission-boundary problems, or issues that could leave the pointer difficult to control.

Do not include undisclosed security details, private diagnostics, personal information, or sensitive system data in a public issue.

For an ordinary functional bug that does not require confidentiality, use the public [bug-report form](https://github.com/mochiya-tako/InnerCorners/issues/new?template=bug_report.yml).

## Safety information

- Hold Option to bypass an active barrier.
- Press Control–Option–Command–Q to disable barriers, save that disabled state, and quit.
- InnerCorners is currently ad-hoc signed and not notarized.
