# Privacy Policy / プライバシーポリシー

Last updated: 2026-11-23

## English

InnerCorners does not collect, transmit, sell, or share personal data. The app contains no analytics, advertising, telemetry, account system, network client, or third-party runtime dependency.

### Data processed on the Mac

To provide its features, InnerCorners processes the following information locally:

- Pointer events and pointer position.
- Connected-display geometry, identifiers, names, resolution, and arrangement.
- The frontmost application's name, bundle identifier, process identifier, and fullscreen state when app-based suppression is evaluated.
- The user's per-display corner assignments, barrier settings, language, excluded-app bundle identifiers, selected application paths, and Shortcut names.
- The corresponding macOS Hot Corners preferences when “Follow macOS Hot Corners” is used.

### Local storage and diagnostics

- Preferences are stored locally in macOS `UserDefaults`.
- A short recent-event history is kept in the app's memory for the diagnostics view.
- Action, corner, display-number, result, safety, and emergency-exit events may be written to Apple's Unified Logging system. Raw pointer coordinates and pointer movement history are not written to those logs.
- Diagnostic text is copied to the clipboard only when the user selects the copy command.

InnerCorners does not send any of this information to the developer or to an external server. Applications, Shortcuts, and macOS system features launched at the user's request are governed by their own privacy behavior.

### Permissions

InnerCorners uses Accessibility permission to monitor and constrain pointer movement and to synthesize input for supported actions. This permission is not used to collect or transmit user content.

### Questions

Privacy questions may be opened as a [GitHub issue](https://github.com/mochiya-tako/InnerCorners/issues). Do not include private or sensitive information in a public issue.

## 日本語

InnerCornersは、個人データの収集・送信・販売・共有を行いません。解析、広告、テレメトリ、アカウント機能、ネットワーク通信機能、外部の実行時依存関係は含まれません。

### Mac上で処理する情報

機能提供のため、次の情報をMac内で処理します。

- ポインタイベントと現在位置。
- 接続画面の形状、識別子、名称、解像度、配置。
- アプリ別抑制の判定時に、最前面アプリの名称、Bundle ID、プロセスID、フルスクリーン状態。
- 画面別のコーナー割当、壁設定、UI言語、除外アプリのBundle ID、選択したアプリパス、ショートカット名。
- 「macOSの標準設定に従う」を使用する場合の、対応するmacOSホットコーナー設定。

### ローカル保存と診断情報

- 設定はmacOSの`UserDefaults`へローカル保存します。
- 診断表示用の短い最近のイベント履歴を、アプリのメモリ内に保持します。
- アクション、コーナー、画面番号、実行結果、安全機構、緊急終了のイベントをAppleの統合ログへ記録する場合があります。ポインタの生座標や移動履歴は統合ログへ記録しません。
- 診断文字列は、ユーザーがコピー操作を選択した場合のみクリップボードへコピーします。

これらの情報を開発者または外部サーバーへ送信することはありません。ユーザーの操作で起動したアプリ、ショートカット、macOSのシステム機能には、それぞれのプライバシー上の挙動が適用されます。

### 権限

InnerCornersは、ポインタ移動の監視・制約と、対応アクションの合成入力のためにアクセシビリティ権限を使用します。この権限をユーザーコンテンツの収集・送信に使用することはありません。

### お問い合わせ

プライバシーに関する質問は[GitHub Issues](https://github.com/mochiya-tako/InnerCorners/issues)で受け付けます。公開Issueに個人情報や機密情報を記載しないでください。
