# InnerCorners OS別ホットコーナーアクション調査

- 調査開始日：2026-11-13
- 調査対象機：macOS 27.0.1 (26A434)、Apple Silicon
- 対応課題：P1-01
- 調査方法：macOS設定値の読み取り、システム設定UIの選択肢確認、OS同梱バイナリ・リソース・コマンドの読み取り
- 非実施：ホットコーナー設定値の変更、非公開APIの呼び出し、実際のロック・スリープ・スクリーンセーバー開始

## 1. macOS 27.0.1で確認した選択肢

システム設定「デスクトップとDock」→「ホットコーナー」のポップアップメニューを開き、次の全項目を目視・アクセシビリティツリーで確認した。選択は行っていない。

1. Mission Control
2. アプリケーションウインドウ
3. デスクトップ
4. 通知センター
5. アプリ
6. クイックメモ
7. スクリーンセーバを開始
8. スクリーンセーバを無効にする
9. ディスプレイをスリープさせる
10. ロック画面
11. なし（メニュー上は`-`）

Appleの利用者向け説明でも、ホットコーナーから通知センター、アプリ、ロック画面、クイックメモ、スクリーンセーバー等を選択できることが案内されている。

- <https://support.apple.com/guide/mac-help/mchlp3000/mac>

## 4. 修飾キー値

現在の4角はすべて`0`で、修飾キーなしと直接確認した。

Dockが従来使用してきた修飾キービットは、CoreGraphicsのフラグと同系統の次の値と考えられるが、現機での直接照合は未実施。

| 修飾キー | 想定値 | 16進数 | 確認状態 |
|---|---:|---:|---|
| Shift | 131072 | `0x00020000` | 未確認 |
| Control | 262144 | `0x00040000` | 未確認 |
| Option | 524288 | `0x00080000` | 未確認 |
| Command | 1048576 | `0x00100000` | 未確認 |

複数キーはビット和になると推定する。OptionはInnerCornersの緊急通過に使用しているため、修飾キー付きアクションより緊急通過を優先する案を基本とし、P1-03で仕様を確定する。

## 5. macOS 27.0.1で確認した実行候補

| アクション | 公開配布を想定した第一候補 | 現在の確認範囲 | 主なリスク |
|---|---|---|---|
| クイックメモ | Apple公式のFn／Globe＋QをCGEventで送る | Apple公式資料でショートカットを確認。送信処理はコンパイル済み、実発動は未確認 | Fn／Globe、外付けキーボード、ショートカット変更 |
| 通知センター | Apple公式のFn／Globe＋NをCGEventで送る | Apple公式資料でショートカットを確認。送信処理はコンパイル済み、実発動は未確認 | Fn／Globe、外付けキーボード、他アプリとの競合 |
| スクリーンセーバ開始 | Bundle ID `com.apple.ScreenSaver.Engine`をNSWorkspaceで解決して起動し、既知パスへフォールバック | macOS 27.0.1でアプリ、Bundle ID、パスを確認。起動処理は実装済み、実発動は未確認 | 旧OSでのBundle解決とパス差、解除後の安全再作動 |
| ロック画面 | 標準のControl＋Command＋QをCGEventで送る | 未実行 | 即時に操作セッションがロックされ、試験に手動解除が必要 |
| ディスプレイスリープ | `/usr/bin/pmset displaysleepnow` | コマンドとman pageの説明を確認。未実行 | 公開APIではなくOSコマンドへの依存、復帰時の画面再認識 |
| スクリーンセーバ無効化 | 公開IOKitの電源アサーション等を調査 | 未調査 | 標準ホットコーナーと同じ範囲だけを抑止できるか不明。状態型処理が必要 |

`DesktopSettings.appex`自体は`_CoreDockGetExposeCornerActionsWithModifiers`および`_CoreDockSetExposeCornerActionWithModifier`を使用しているが、これは非公開CoreDock関数である。InnerCornersの公開向け実装には使用しない。

## 7. P1-01の判定

### 完了した部分

- macOS 27.0.1の標準アクション全一覧
- 現在の4角のraw値と修飾キー値
- 未実装6機能の存在
- 各機能の公開向け実行候補
- OS同梱の設定画面が非公開CoreDock関数を使う事実

### 未完了の部分

- 未割当6機能のraw値をこのMacで直接照合
- 修飾キービットの直接照合
- macOS 14、15、26での一覧・パス・動作確認
- 各実行候補を実際に発動した試験

P1-02の設計には進める。ただしアクション値は確定値と仮定値を型で区別し、実機照合が済むまで公開版の「対応済み」にはしない。
